# rlxeducode

## design ideas

- The student runs an open coding agent
  - [`Pi`](https://pi.dev/), based in TypeScript) or
  - [`Tau`](https://twotimespi.dev/) (based in Python and maybe easier to integrate [`rlxcrypt`](https://pypi.org/project/rlxcrypt/) within)

- The coding agent will be customized (fork, or through skills, etc.) to support an authenticated, encrypted workflow of automated lab/task execution and auto-grading.

- Runtime:
  - We will only support students running the coding agent on colab using [`google-colab-cli`](https://github.com/googlecolab/google-colab-cli).
  - This way labs/tasks requiring GPUs, just like colab notebooks. 
  - A student might run the coding agent together with labs/tasks on his laptop but this will not be generally supported.

- Labs/Tasks 
  - delivered as SKILLS with encrypted python auto-graders
  - very granular, with many submitable/intermediate auto-graded steps
  - submitted from the coding agent through a slash-command probably
  - submission encrypted python logic within the task skill will make sure it was invoked from our coding agent

- Backend
  - an `rlxeducode` backend will register submissions, keep track of grading
  - will expose a web app for students to see their progress

- Quizes
  - frequent and online
  - fast and with a lot of granular questions
  - questions will be generated by a teacher designed prompt using some frontier model upon the task defition.
  - with this, each student will get his own individually generated questions.
  - done through rlxeducode web, which will provide some proctored environemt (camera, etc.)
